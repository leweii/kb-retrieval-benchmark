对比的维度

维度取值
知识库体量300 / 900 / 3000 篇，嵌套（300 ⊂ 900 ⊂ 3000），文档组成见附录 B
模型Claude Haiku 5.5、Claude Sonnet 5.5（Anthropic API，effort medium）；DeepSeek V4.1 Flash（DeepSeek 官方 API，默认 effort high，该 API 没有 medium 档）
检索方式R1 grep（正则搜全文 + 读文件）· R2 BM25 · R3 混合（BM25 + 向量，RRF 融合）· R4 增强混合（QMD 式：Haiku 查询扩展 → BM25 + 向量 → RRF → Haiku 重排 30 个候选）· R5 LLM-wiki 导航（从 index.md 顺链接读，可回读原文）· R6 LLM-wiki + 混合检索
使用模式单次：用问题检索一次，取前 8 段交给模型作答 · 两轮：材料不够时，模型联想出 1–3 个新查询再检索一次，仍没有就拒答 · 智能体：模型自己调用工具（搜索 / grep / 列目录 / 读文件），最多 12 步

组件

  • 向量：qwen3-embedding-8b（OpenRouter，固定服务商 DeepInfra）；本地 numpy 暴力检索，不用向量数据库。切块按 markdown 标题，约 600 token。
  • LLM-wiki：Claude Haiku 5.5 逐篇提炼（摘要、关键事实、实体），代码汇总成 index / 主题页 / 摘要页 / 实体页。50 篇盲评中 Haiku 与 Sonnet 提炼质量相当。
  • 统一提示词：具体事实必须来自知识库；可以用常识理解和串联知识库内容，不能用常识补缺；库里没有要明确说。智能体检索策略：先搜关键词（非英文问题同时用英文关键词）→ 没结果就联想后再搜 → 多步问题逐块找 → 仍没有才拒答。

评分与指标

指标定义
准确率MuSiQue 可回答题的答案是否与标准答案或别名一致（Claude Opus 5.5 判定）。只统计 115 道干净题：剔除了任一被测模型不查知识库就能答对的 32 道
找全证据多跳题的全部证据文档都曾展示给模型：检索段落、搜索摘要、grep 命中行或打开读取（wiki 摘要页映射回原文）。这个比例随搜索 / grep 次数机械增长（一次 grep 最多列出 60 个文件），只说明证据出现过，不代表搜得更彻底
误拒MuSiQue / BRIGHT 可回答题，回答"知识库里没有"的比例
说"不知道"不可回答题中明确表示知识库没有的比例；直接给出答案算幻觉
p50 耗时从提问到最终答案的端到端时间中位数，多进程并发负载下测得
单题花费模型调用 + 检索 API（embedding、R4 的查询扩展和重排）按各家实际价格计算
轮次每道题调用被测模型的次数：单次 = 1；两轮 = 1–3；智能体每轮一次调用，最多 12 轮，用满后再强制作答 1 次（因此最多 13）。"用满步数"= 达到 12 轮上限的比例
工具调用次数每道题调用搜索 / grep / 列目录 / 读文件等工具的总次数（两轮模式的"再搜一次"算 1 次）；智能体一轮可以并行调用多个工具
  • 评分：Claude Opus 5.5（不在被测模型之列），Message Batches；共 26,730 条回答全部评分。BRIGHT 是开放问题、NoLiMa 主要考联想检索，这两组只评检索和拒答，不评答案准确率。没有给出回答的运行（报错或空答案）按失败计：可回答题算答错、算未作答，不可回答题不算正确拒答。
  • 推荐规则：只在"说不知道 ≥ 70% 且已评分 MuSiQue ≥ 30 题"的组合中比较；质量首选 = 准确率最高；性价比 = 与首选差距 ≤ 5 个百分点中最便宜；Flash 级 = 只在 Haiku / DeepSeek 中选。
  • 关键差异的检验见下方"显著性与稳健性"。

局限

  • 公开数据集不是个人 md 笔记：同一项目多篇笔记、版本冲突、写法与问法不一致等个人知识库特有的难点没有覆盖。
  • Claude 用 effort medium、DeepSeek 用 high，思考强度不完全对等。
  • 闭卷记忆过滤：出题时只用 Sonnet 过滤；Haiku 和 DeepSeek 是事后补测的，DeepSeek 有 24 条闭卷预测为空，相当于没测。
  • 体量之间不只差干扰文档的数量（见附录 B）：300 / 900 篇里几乎没有同题的易混淆文档，体量曲线同时混入了这个因素。
  • 中文题保留了英文专有名词（多数含金标文档标题），基本没有测到跨语言检索。
  • 耗时在并发负载下测得，不同 API 通道之间不宜直接比较。智能体最多 12 步；用满步数的比例：Haiku 5.5 1%、Sonnet 5.5 1%、DeepSeek V4.1 Flash 27%，结果对步数上限敏感。
  • R4 的重排用 Haiku 代替 QMD 原版的 Qwen3-Reranker（16 题对比召回相同）。千问 3.8 Flash 因 API 额度未参与。
